## 1. 理解 Project 2 必知的 7 个 VHDL 核心语法

1. **`record`（结构体）与 `array` 组合**：将单只地鼠的 7 项属性（`active`、`x`、`y`、`kind`、`hp`、`mining`、`mine_timer`）打包为 `mole_rec_t`，并通过 `mole_array_t` 管理 8 个槽位（`0 to 7`）。
2. **硬件 `for ... loop` 与 `exit;`**：VHDL 中的 `for i in 0 to 7 loop` 并非软件里的顺序迭代，而是**将相同的硬件电路并行展开复制 8 份（Unrolling）**。在寻找 1 个空槽位进行召唤时，必须使用 `exit;` 跳出循环，才能防止 8 只地鼠同时被召唤。
3. **双向端口 `inout` 与 `'Z'`（开漏输出，Open-Drain）**：由于 FPGA 与鼠标共用同一根 `PS2_CLK`、`PS2_DAT` 信号线，当 FPGA 不将其拉低为 `'0'` 时，必须输出 `'Z'`（高阻态，High-Impedance），鼠标才能驱动该信号线。
4. **位拼接运算符 `&` 与 `signed`**：像 `ps2_dat_sync(1) & shift_reg(10 downto 1)` 这样将位拼接起来构建移位寄存器，并像 `signed(pkt_byte0(4) & pkt_byte1)` 这样将符号位与数值位合并，以还原带正负号的位移量（`dx`、`dy`）。
5. **枚举型状态机 FSM（`type state_t is (...)`）**：将 PS/2 鼠标的初始化与接收阶段定义为 7 个直观的状态名称，并通过 `case state is` 进行控制。
6. **`procedure`（多输出辅助过程）**：`function` 只能 `return` 1 个值，而 `procedure set_rgb(...)` 可以同时更新 `r10`、`g10`、`b10` 3 个变量。
7. **字符串索引规则（`1 to N`）**：VHDL 的 `string` 索引从 `1` 开始，因此在将 `0..15` 坐标转换访问时，需要像 `(sprite_x + 1)`、`(char_col + 1)` 这样加上 `+1` 偏移量。

## 3. 文件 1: [sprite_reward_pkg.vhd](./sprite_reward_pkg.vhd)

### 3.1 地鼠结构体与精灵图类型 (Lines 12~30)

```vhdl
12: package sprite_reward_pkg is
14:     constant MAX_MOLES : integer := 8;
17:     type mole_rec_t is record
18:         active     : std_logic;
19:         x          : integer range 0 to 511;
20:         y          : integer range 0 to 511;
21:         kind       : std_logic;             -- '0' = Diglett (두더류), '1' = Excadrill (몰드류)
22:         hp         : integer range 0 to 7;  -- Remaining hits to kill (R1:1/2, R2:2/4, R3:3/6)
23:         mining     : std_logic;             -- '1' when within mining distance of coin pile
24:         mine_timer : integer range 0 to 63; -- 0..59 (60 ticks at 60Hz = 1.0 second mining motion)
25:     end record;
27:     type mole_array_t is array (0 to MAX_MOLES - 1) of mole_rec_t;
30:     type sprite_16x16_t is array (0 to 15) of string(1 to 16);
```

- **Line 14 (`MAX_MOLES := 8`)**：场上同时能存在的最大地鼠槽位数量。
- **Lines 17~25 (`mole_rec_t`)**：用于封装单只地鼠状态的记录体（record）。
  - `active`：`'1'` 表示存活，`'0'` 表示空槽位。
  - `x, y`：480×480 地图内的坐标（优化为 `0 to 511` 的 9 位范围）。
  - `kind`：`'0'` 为普通地鼠（Diglett/螺钉地鼠），`'1'` 为生命值翻倍且移速更快的特殊地鼠（Excadrill/龙头地鼠）。
  - `hp`：剩余生命值（`0 to 7`，3 位）。各回合中普通地鼠生命值为 `1/2/3`，龙头地鼠生命值为 `2/4/6`。
  - `mining`、`mine_timer`：是否到达中央硬币堆以及 1 秒（60 帧 `0..59`）挖矿计时器。
- **Line 30 (`sprite_16x16_t`)**：存放 16 行 × 16 字符（`string(1 to 16)`）像素画的二维 ROM 类型。

### 3.2 精灵图 ROM、奖励/规则叠加层文本、5×7 字体 ROM (Lines 37~335)

- **Lines 37~165**：定义了 `SPRITE_DIGLETT`、`SPRITE_EXCADRILL`、按连击阶段进化的 3 种锤子（`SPRITE_HAMMER_1`、`SPRITE_HAMMER_2`、`SPRITE_HAMMER_3`）以及中央硬币堆（`SPRITE_COIN`）的 16×16 调色板字符表。
- **Lines 179~221 (`REWARD_OVERLAY_TEXT`, `RULE_OVERLAY_TEXT`)**：
  - 大小为 `16 行 × 34 列`（`reward_text_t`）的定长字符串数组。
  - `RULE_OVERLAY_TEXT`：游戏开始前 `10..4 秒` 区间显示的规则说明画面。
  - `REWARD_OVERLAY_TEXT`：游戏结束时显示的 **50 MMC 奖励 Cloudflare 链接（`/r/1`~`/r/5`）与 5 组 16 位一次性领取码**表格。*（每行长度必须固定为 34 个字符）*
- **Lines 224~335 (`get_font_pixel`)**：
  - 接收字符 `ch`、行 `row(0..6)`、列 `col(0..4)` 作为输入，返回 5×7 点阵字体中对应像素是否点亮（`'1'`/`'0'`）的纯组合逻辑函数。

## 4. 文件 2: [vga_controller.vhd](./vga_controller.vhd)

### 4.1 时序常数与 25MHz 分频/坐标计数器 (Lines 29~82)

```vhdl
30:     constant H_DISPLAY : integer := 640; -- Visible horizontal area
31:     constant H_FRONT   : integer := 16;  -- Horizontal front porch
32:     constant H_SYNC    : integer := 96;  -- Horizontal sync pulse width
33:     constant H_BACK    : integer := 48;  -- Horizontal back porch
34:     constant H_TOTAL   : integer := 800; -- Total pixels per line (640+16+96+48)
37:     constant V_DISPLAY : integer := 480; -- Visible vertical area
38:     constant V_FRONT   : integer := 10;  -- Vertical front porch
39:     constant V_SYNC    : integer := 2;   -- Vertical sync pulse width
40:     constant V_BACK    : integer := 33;  -- Vertical back porch
41:     constant V_TOTAL   : integer := 525; -- Total lines per frame (480+10+2+33)
```

- **Lines 30~41**：640×480 @ 60Hz VESA 标准时序常数。每帧共由 $800 \times 525 = 420,000$ 个像素时钟组成，基于 25MHz 时钟以 $25,000,000 / 420,000 \approx 59.52\text{ Hz}$ 的频率刷新画面。
- **Lines 51~82 (`process(CLOCK_50, reset_n)`)**：
  - **Line 53 (`if reset_n = '0' then`)**：按下 `KEY(3)`（低电平有效，Active-Low）时通过异步复位将所有计数器清 `0`。
  - **Line 60 (`clk_25 <= not clk_25;`)**：在 50MHz 时钟的每个上升沿翻转，生成精确的 **25MHz 像素时钟（`vga_clk`）**。
  - **Line 61 (`frame_tick <= '0';`)**：默认保持 `'0'`，仅在满足下方第 77 行条件时置 `'1'` **恰好 1 个时钟周期（20ns）**。
  - **Lines 64~74 (`if clk_25 = '1' then`)**：每当 `clk_25` 为 `'1'` 的周期（25MHz，每 2 个主时钟 1 次），将 `h_cnt` 从 `0..799` 递增，到达行尾时将 `v_cnt` 从 `0..524` 递增。
  - **Lines 77~79 (`if h_cnt = 0 and v_cnt = V_DISPLAY then frame_tick <= '1';`)**：在可见区域第 480 行（`0..479`）刚刚结束的 `v_cnt = 480, h_cnt = 0` 时刻产生 **`frame_tick` 60Hz 脉冲**。游戏引擎同步该信号更新坐标，可避免画面扫描期间发生画面撕裂（Tearing）。

### 4.2 同步信号与 DAC 输出 (Lines 85~97)

```vhdl
85:     hsync <= '0' when (h_cnt >= H_DISPLAY + H_FRONT and h_cnt < H_DISPLAY + H_FRONT + H_SYNC) else '1';
86:     vsync <= '0' when (v_cnt >= V_DISPLAY + V_FRONT and v_cnt < V_DISPLAY + V_FRONT + V_SYNC) else '1';
89:     vid_on   <= '1' when (h_cnt < H_DISPLAY and v_cnt < V_DISPLAY) else '0';
92:     video_on <= vid_on;
93:     blank_n  <= vid_on;
94:     sync_n   <= '0';
95:     vga_clk  <= clk_25;
96:     pixel_x  <= h_cnt;
97:     pixel_y  <= v_cnt;
```

- **Lines 85~86**：由于 640×480 VGA 的行/场同步信号为**低电平有效（Active-Low）**，仅在行消隐前肩（Front Porch）之后的同步脉冲宽度区间（`h_cnt: 656~751`、`v_cnt: 490~491`）输出 `'0'`。
- **Lines 89~97**：仅在实际显示区域（`h_cnt < 640` 且 `v_cnt < 480`）内输出 `video_on = '1'`、`blank_n = '1'`，使 DE2 开发板的 ADV7123 DAC 输出颜色信号。

## 5. 文件 3: [ps2_mouse_unit.vhd](./ps2_mouse_unit.vhd)

### 5.1 开漏（Open-Drain）驱动与边沿检测 (Lines 69~88)

```vhdl
70:     PS2_CLK <= '0' when clk_out_en = '1' else 'Z';
71:     PS2_DAT <= '0' when (dat_out_en = '1' and dat_out_val = '0') else 'Z';
80:     process(CLOCK_50)
81:     begin
82:         if rising_edge(CLOCK_50) then
83:             ps2_clk_sync <= ps2_clk_sync(1 downto 0) & PS2_CLK;
84:             ps2_dat_sync <= ps2_dat_sync(0) & PS2_DAT;
85:         end if;
86:     end process;
88:     ps2_clk_fall <= '1' when (ps2_clk_sync(2) = '1' and ps2_clk_sync(1) = '0') else '0';
```

- **Lines 70~71**：PS/2 总线采用带有上拉电阻的开漏结构。只有当 FPGA 需要输出 `'0'` 时才将其拉低至 GND，平时必须置于 `'Z'`（断开高阻态），鼠标才能发送时钟与数据。
- **Lines 80~88**：为将鼠标产生的异步 `PS2_CLK`（约 10~16kHz）同步至 50MHz 时钟域，使用 3 级移位寄存器 `ps2_clk_sync`，并通过 `ps2_clk_sync(2)='1' and ps2_clk_sync(1)='0'` 检测**稳定的下降沿（`ps2_clk_fall`）**。

### 5.2 七状态 FSM：`0xF4` 初始化与 3 字节数据包接收 (Lines 111~235)

1. **`INIT_WAIT` (Lines 114~122)**：上电/复位后等待 `40ms`（2,000,000 个时钟周期），直至鼠标内部 MCU 完成稳定初始化。
2. **`TX_PULL_CLK_LOW` (Lines 125~132)**：主机（FPGA）为发起发送请求，将 `PS2_CLK` 拉低为 `'0'` 持续 `150us`（7,500 个时钟周期）。
3. **`TX_PULL_DAT_LOW` (Lines 135~144)**：将 `PS2_DAT` 拉低为 `'0'`（起始位 Start Bit）后释放 `PS2_CLK`（`clk_out_en <= '0'`），鼠标随即开始生成时钟。
4. **`TX_SEND_BITS` (Lines 147~156)**：在每个 `ps2_clk_fall` 时发送 `CMD_F4_FRAME`（`"1011110100"` = 停止位 `1` + 奇校验位 `0` + 从 LSB 开始的 `0xF4`）共 10 位数据。
5. **`TX_WAIT_ACK` / `RX_WAIT_ACK_BYTE` (Lines 159~175)**：接收并忽略鼠标返回的 ACK 位以及 `0xFA`（11 位帧）应答后，进入数据流模式（Stream Mode）。
6. **`RX_STREAM_PACKETS` (Lines 178~233)**：
   - **Line 181**：`shift_reg <= ps2_dat_sync(1) & shift_reg(10 downto 1);` —— 从 LSB 起逐位右移接收 11 位帧（Start + 8 Data + Parity + Stop）。
   - **Line 185**：在第 11 位（`bit_cnt = 10`）时通过 `shift_reg(9 downto 2)` 提取 8 位数据。
   - **Lines 187~199**：在 `byte_idx = 0` 时校验 PS/2 数据包同步验证位 `rx_byte(3) = '1'`，随后保存左键点击（`rx_byte(0)`）与右键点击（`rx_byte(1)`）。在 `byte_idx = 1` 时保存 `dX` 数值（`pkt_byte1`）。
   - **Lines 202~229**：在 `byte_idx = 2` 时将 `pkt_byte0(4) & pkt_byte1`（9 位有符号 `dx`）与 `pkt_byte0(5) & rx_byte`（9 位有符号 `dy`）从 `signed` 转换为 `integer`。由于鼠标向上为 `+Y` 而显示器向下为 `+Y`，因此通过 `new_y := cur_y - dy;` 反转符号，并将其限幅（Clamping）在 480×480 地图内部（`16..463`）。

## 6. 文件 4: [game_engine_unit.vhd](./game_engine_unit.vhd)

### 6.1 常数、坐标查找表（LUT）与游戏状态寄存器 (Lines 50~93)

- **Lines 51~54**：中央硬币堆 `(240, 240)`，锤子攻击半径平方 `ATTACK_RADIUS_SQ := 48 * 48 = 2304`，开始挖矿距离 `MINE_DISTANCE := 26`。
- **Lines 57~69 (`SPAWN_X_LUT`, `SPAWN_Y_LUT`)**：将中央禁区（`140..340`）外围的 12 个区域按顺时针方向（Zone 0 左上 `(60, 50)` ~ Zone 11 左侧偏上 `(50, 180)`）布置的坐标查找表。
- **Lines 72~92**：`px, py`（人物初始位置 `(240, 320)`）、`atk_timer`（挥锤动作 12 帧）、`stun_timer`（挥空硬直 30 帧 = 0.5 秒）、`combo_cnt`（连续击杀连击数）、`coins := 50`（累计 50 硬币）、`sec_left := 20`（1R/2R 20 秒，3R 30 秒）、`cur_round := 1`、`intro_sec := 10`（10 秒开场引导）、`rand_cnt`（以 50MHz 高速循环的 `0..7` 随机数计数器）、`last_spawn_zone`（记录上一次召唤的区域）。

### 6.2 玩家 1 锤子攻击与连击/硬直系统 (Lines 167~231)

```vhdl
167: attack_req := (not attack_key_n) or mouse_lclick;
169: if state = 0 and intro_sec = 0 and attack_req = '1' and atk_prev = '0' and
170:    atk_timer = 0 and stun_timer = 0 then
```

- **Line 167**：按下开发板按键 `KEY(0)`（低电平有效，故取 `not`）或鼠标左键中的任意一个，均会触发攻击请求。
- **Lines 169~170**：仅在游戏进行中（`state = 0`）、开场引导结束（`intro_sec = 0`）、攻击按键上升沿（`attack_req = '1' and atk_prev = '0'`）且不处于冷却/硬直状态时才进行打击判定。
- **Lines 176~188**：遍历 8 个槽位，在 `dx^2 + dy^2 <= 2304`（$R=48$）范围内寻找**距离最近的 1 只地鼠（`closest_idx`）**。（无需开方运算，直接比较平方距离以节省 FPGA 硬件资源。）
- **Lines 191~217（命中时）**：
  - 按连击数计算伤害：若 `combo_cnt >= 9`，则有 `rand_cnt < 4`（4/8 概率）触发暴击伤害 `3`（否则为 `2`）；若 `combo_cnt >= 3` 则为 `2` 伤害；基础为 `1` 伤害。
  - 若 `hp > atk_dmg` 则仅扣除对应生命值；若 `hp <= atk_dmg` 则使地鼠失活（`active <= '0'`）并将 `kills` 与 `combo_cnt` 各加 1。
- **Lines 218~229（挥空时）**：若攻击范围内没有地鼠，则施加 `stun_timer <= 30`（0.5 秒无法移动和攻击），并将连击等级下降 1 级（`9+ -> 6`、`6..8 -> 3`、`0..5 -> 0`）。

### 6.3 60Hz 帧更新：开场引导 · 回合切换 · P1 移动 · 召唤 · AI/挖矿 (Lines 236~470)

- **Lines 248~254（10 秒开场引导）**：`intro_sec` 每 1 秒（60 帧）从 10 递减至 0。（`10..4 秒` 显示规则说明，`3..1 秒` 显示倒计时）
- **Lines 256~279（胜负与回合切换）**：
  - 若 `coins = 0`，立即判定地鼠获胜（`state <= 2`）。
