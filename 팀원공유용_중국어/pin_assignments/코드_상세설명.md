# DE2 开发板引脚分配 (Pin Assignments) 说明文档

本目录（`pin_assignments`）包含在 Altera/Intel **DE2 开发板（Cyclone II `EP2C35F672C6`）** 上综合集成顶层模块（`de2_unified_top`）及 Project 2 时，可在 Quartus 中一键导入的引脚映射文件。

---

## 1. 文件清单与用途

| 文件名 | 目标工程 | 包含引脚配置 | 使用方法 |
| :--- | :--- | :--- | :--- |
| **[project2_pin_assignments.csv](./project2_pin_assignments.csv)** | **集成顶层 (`de2_unified_top`) & Project 1·2 全部** | `CLOCK_50`, `SW[17:0]`, `KEY[3:0]`, `HEX0~HEX7`, `LEDR[17:0]`, `LEDG[7:0]` + **`VGA` 输出引脚（35 个）** + **`PS/2 鼠标` 引脚（2 个）**（共 142 个引脚） | 在 Quartus 菜单 `Assignments -> Import Assignments...` 中选择导入 |
| **[project2_pin_locations_only.txt](./project2_pin_locations_only.txt)** | **集成顶层 (`de2_unified_top`)** | 142 个引脚位置编号汇总表 | 用于快速核对引脚编号 |

---

## 2. Project 2 新增外设模块引脚映射摘要 (`project2_pin_assignments.csv`)

### 2.1 PS/2 有线光电鼠标（Player 1 移动及左键点击攻击）
| VHDL 端口名 | DE2 引脚编号 | 方向 | 说明 |
| :--- | :---: | :---: | :--- |
| **`PS2_CLK`** | `PIN_D26` | `inout` | PS/2 鼠标时钟线（双向开漏） |
| **`PS2_DAT`** | `PIN_C24` | `inout` | PS/2 鼠标数据线（双向开漏） |

### 2.2 VGA 显示器/电视输出（ADV7123 10-bit DAC ➔ VGA / VGA-to-HDMI 转换器）
| VHDL 端口名 | DE2 引脚编号 | 说明 |
| :--- | :--- | :--- |
| **`VGA_CLK`** | `PIN_B8` | 25MHz VGA 像素时钟 |
| **`VGA_HS`, `VGA_VS`** | `PIN_A7`, `PIN_D8` | 行同步 (H-Sync) 与场同步 (V-Sync) |
| **`VGA_BLANK`, `VGA_SYNC`** | `PIN_D6`, `PIN_B7` | DAC 消隐及同步控制信号 |
| **`VGA_R[9:0]`** | `PIN_C8`, `F10`, `G10`, `D9`, `C9`, `A8`, `H11`, `H12`, `F11`, `E10` | Red 通道 10 位 |
| **`VGA_G[9:0]`** | `PIN_B9`, `A9`, `C10`, `D10`, `B10`, `A10`, `G11`, `D11`, `E12`, `D12` | Green 通道 10 位 |
| **`VGA_B[9:0]`** | `PIN_J13`, `J14`, `F12`, `G12`, `J10`, `J11`, `C11`, `B11`, `C12`, `B12` | Blue 通道 10 位 |
