# DE2 集成项目（Project 1 + Project 2）整体结构与代码详解

本文档整理了运行在 Altera/Intel **DE2 开发板（Cyclone II `EP2C35F672C6`，50MHz `CLOCK_50`）** 上的 **Project 1（计数器 & 一位数计算器）** 与 **Project 2（Crypto Miner Defense 打地鼠游戏）** 的 **全部 VHDL 源代码功能、层级结构及模块间信号连接**。

---

## 1. 整体层级结构 (System Hierarchy)

在一个 Quartus 工程（`de2_unified_top`）中，共有 **11 个 VHDL 文件**按层级连接，仅通过 **`SW(4)`** 一个拨码开关即可在 Project 1 和 Project 2 之间实时切换。

```text
de2_unified_top.vhd  (主顶层实体，SW(4) 模式切换)
│
├── [SW(4) = '0'] ──▶ project1_top_countercalculator.vhd  (Project 1 子顶层)
│                     ├── [SW(0) = '0'] ──▶ counter_unit.vhd     (计数器 + 777 彩蛋)
│                     └── [SW(0) = '1'] ──▶ calculator_unit.vhd  (一位数四则运算计算器)
│
└── [SW(4) = '1'] ──▶ project2_top_mole_game.vhd          (Project 2 子顶层)
                      ├── vga_controller.vhd     (640x480 @ 60Hz 时序，frame_tick)
                      ├── ps2_mouse_unit.vhd     (PS/2 鼠标 0xF4 初始化与坐标)
                      ├── game_engine_unit.vhd   (3 回合游戏物理·AI·SW(17..6) 召唤)
                      └── vga_renderer_unit.vhd  (实时像素图形与奖励弹窗)

[公共包引用 (use work.*)]
├── seg7_pkg.vhd           ──▶ counter_unit, calculator_unit, project2_top_mole_game
└── sprite_reward_pkg.vhd  ──▶ game_engine_unit, vga_renderer_unit, project2_top_mole_game
```

## 2. 主顶层模块：`de2_unified_top.vhd`（逐行详解）

[de2_unified_top.vhd](./de2_unified_top.vhd) 直接接收 DE2 开发板的物理引脚（`CLOCK_50`、`SW`、`KEY`、`HEX0~7`、`LEDR`、`LEDG`、`PS2_*`、`VGA_*`），将其分配给内部的 `U_PROJECT1` 与 `U_PROJECT2`，并安全隔离未激活项目的状态，是整个系统的**主顶层（Top-Level）实体**。

### 2.1 库引用与实体 (Entity) 声明部分 (Lines 1~17)

```vhdl
 1: library ieee;
 2: use ieee.std_logic_1164.all;
 3: 
 4: -- Master Top-Level Entity: de2_unified_top (SW(4)='0' -> Project 1, SW(4)='1' -> Project 2)
 5: entity de2_unified_top is
 6:     port (
 7:         CLOCK_50                                        : in    std_logic;
 8:         SW                                              : in    std_logic_vector(17 downto 0);
 9:         KEY                                             : in    std_logic_vector(3 downto 0);
10:         HEX0, HEX1, HEX2, HEX3, HEX4, HEX5, HEX6, HEX7  : out   std_logic_vector(6 downto 0);
11:         LEDR                                            : out   std_logic_vector(17 downto 0);
12:         LEDG                                            : out   std_logic_vector(7 downto 0);
13:         PS2_CLK, PS2_DAT                                : inout std_logic;
14:         VGA_CLK, VGA_HS, VGA_VS, VGA_BLANK, VGA_SYNC    : out   std_logic;
15:         VGA_R, VGA_G, VGA_B                             : out   std_logic_vector(9 downto 0)
16:     );
17: end entity de2_unified_top;
```

- **Lines 1~2**：引入 `ieee.std_logic_1164` 以使用标准数字信号（`std_logic`、`std_logic_vector`）。顶层模块不直接执行算术运算，仅进行连线（Structural），因此无需引入 `numeric_std`。
- **Line 7 (`CLOCK_50 : in std_logic;`)**：接收 DE2 板载 50MHz 时钟，并同时提供给 Project 1 和 Project 2。
- **Lines 8~9 (`SW`, `KEY`)**：DE2 开发板的 18 个拨码开关（`SW(17..0)`）和 4 个低电平有效按键（`KEY(3..0)`）输入。
- **Lines 10~12 (`HEX0~7`, `LEDR`, `LEDG`)**：两个项目共享板载的 8 位七段数码管、18 个红色 LED 和 8 个绿色 LED，因此根据 `SW(4)` 的状态选择输出哪一个项目的结果。
- **Line 13 (`PS2_CLK, PS2_DAT : inout std_logic;`)**：与 PS/2 光电鼠标进行双向开漏（Open-Drain）通信的 `inout` 端口，直接连接到 Project 2（`U_PROJECT2`）。
- **Lines 14~15 (`VGA_*`)**：输出到 DE2 板载 ADV7123 VGA DAC 芯片的 25MHz 像素时钟（`VGA_CLK`）、行/场同步（`VGA_HS`、`VGA_VS`）、消隐/同步控制（`VGA_BLANK`、`VGA_SYNC`）以及 10 位 RGB 色彩（`VGA_R`、`VGA_G`、`VGA_B`）。

### 2.2 内部信号声明与输入隔离 (Isolation) 逻辑 (Lines 19~36)

```vhdl
19: architecture structural of de2_unified_top is
20:     signal proj_sel                               : std_logic;
21:     signal p1_KEY, p2_KEY                         : std_logic_vector(3 downto 0);
22:     signal p2_SW                                  : std_logic_vector(17 downto 0);
23:     signal p1_HEX0, p1_HEX1, p1_HEX2, p1_HEX3     : std_logic_vector(6 downto 0);
24:     signal p1_HEX4, p1_HEX5, p1_HEX6, p1_HEX7     : std_logic_vector(6 downto 0);
25:     signal p2_HEX0, p2_HEX1, p2_HEX2, p2_HEX3     : std_logic_vector(6 downto 0);
26:     signal p2_HEX4, p2_HEX5, p2_HEX6, p2_HEX7     : std_logic_vector(6 downto 0);
27:     signal p1_LEDR, p2_LEDR                       : std_logic_vector(17 downto 0);
28:     signal p1_LEDG, p2_LEDG                       : std_logic_vector(7 downto 0);
29: begin
30: 
31:     -- SW(4) is unused in both Project 1 (SW(3..0), SW(17..10)) and Project 2 (SW(17..6)),
32:     -- and leaves SW(5) as a physical buffer gap next to SW(6).
33:     proj_sel <= SW(4);
34:     p1_KEY   <= KEY when proj_sel = '0' else "1111";
35:     p2_KEY   <= KEY when proj_sel = '1' else "0111"; -- Hold KEY(3)='0' (Reset) while in Project 1
36:     p2_SW    <= SW  when proj_sel = '1' else (others => '0');
```

- **Line 19 (`architecture structural ...`)**：声明**结构化（Structural）建模**，即内部不直接计算算法，而是通过信号线组装下层模块（`U_PROJECT1`、`U_PROJECT2`）。
- **Lines 20~28（内部信号）**：声明用于隔离各模块输入的 `p1_KEY`、`p2_KEY`、`p2_SW`，以及用于在送入多路复用器前暂存两个模块输出的 `p1_HEX*`、`p2_HEX*`、`p1_LEDR/G`、`p2_LEDR/G` 信号线。
- **Line 33 (`proj_sel <= SW(4);`)**：
  - Project 1 使用 `SW(3..0)`（模式/运算/进制）和 `SW(17..10)`（操作数 A、B），Project 2 使用 `SW(17..6)`（12 个区域召唤地鼠）。
  - 因此选用双方均未使用的 **`SW(4)`** 作为主项目切换开关，并保留紧邻 `SW(6)` 的 `SW(5)` 作为**物理缓冲间隔（Buffer Gap）**，防止在操作地鼠召唤开关（`SW(6)`）时误触 `SW(4)`。
- **Line 34 (`p1_KEY <= KEY when proj_sel = '0' else "1111";`)**：
  - 在游玩 Project 2 期间（`proj_sel = '1'`），即使用户按下 `KEY(0)`（锤击）或 `KEY(3)`（游戏复位），为了防止 Project 1 的计数值发生变化，未激活时向 Project 1 传入“所有按键均未按下（`"1111"`，低电平有效）”状态进行隔离。
- **Line 35 (`p2_KEY <= KEY when proj_sel = '1' else "0111";`)**：
  - 反之，在使用 Project 1 期间（`proj_sel = '0'`），持续向 Project 2 的复位引脚 `KEY(3)` 输入 `'0'`（`"0111"`，仅第 3 位为 `'0'`），使游戏保持在复位等待状态。一旦将 `SW(4)` 拨至 `'1'`，复位解除，Project 2 开场（10 秒规则说明）即可干净启动。
- **Line 36 (`p2_SW <= SW when proj_sel = '1' else (others => '0');`)**：
  - 防止为 Project 1 计算器拨上的 `SW(17..10)` 数值误作为 Project 2 的地鼠召唤输入，未激活时将其屏蔽为 `'0'`。

### 2.3 子项目实例化与全局输出多路复用器 (Lines 39~76)

```vhdl
39:     -- 1. Project 1: Counter + One-Digit Calculator (Active when SW(4) = '0')
40:     U_PROJECT1 : entity work.project1_top_countercalculator
41:         port map (
42:             CLOCK_50 => CLOCK_50, SW => SW, KEY => p1_KEY,
43:             HEX0 => p1_HEX0, HEX1 => p1_HEX1, HEX2 => p1_HEX2, HEX3 => p1_HEX3,
44:             HEX4 => p1_HEX4, HEX5 => p1_HEX5, HEX6 => p1_HEX6, HEX7 => p1_HEX7,
45:             LEDR => p1_LEDR, LEDG => p1_LEDG
46:         );
47: 
48:     -- 2. Project 2: Crypto Miner Defense Mole Game (Active when SW(4) = '1')
49:     U_PROJECT2 : entity work.project2_top_mole_game
50:         port map (
51:             CLOCK_50 => CLOCK_50, SW => p2_SW, KEY => p2_KEY,
52:             HEX0 => p2_HEX0, HEX1 => p2_HEX1, HEX2 => p2_HEX2, HEX3 => p2_HEX3,
53:             HEX4 => p2_HEX4, HEX5 => p2_HEX5, HEX6 => p2_HEX6, HEX7 => p2_HEX7,
54:             LEDR => p2_LEDR, LEDG => p2_LEDG,
55:             PS2_CLK => PS2_CLK, PS2_DAT => PS2_DAT,
56:             VGA_CLK => VGA_CLK, VGA_HS => VGA_HS, VGA_VS => VGA_VS,
57:             VGA_BLANK => VGA_BLANK, VGA_SYNC => VGA_SYNC,
58:             VGA_R => p2_VGA_R, VGA_G => p2_VGA_G, VGA_B => p2_VGA_B
59:         );
60: 
61:     -- 3. Global Output Multiplexer (SW(4) = '0' -> Project 1, SW(4) = '1' -> Project 2)
62:     HEX0  <= p1_HEX0 when proj_sel = '0' else p2_HEX0;
63:     HEX1  <= p1_HEX1 when proj_sel = '0' else p2_HEX1;
64:     HEX2  <= p1_HEX2 when proj_sel = '0' else p2_HEX2;
65:     HEX3  <= p1_HEX3 when proj_sel = '0' else p2_HEX3;
66:     HEX4  <= p1_HEX4 when proj_sel = '0' else p2_HEX4;
67:     HEX5  <= p1_HEX5 when proj_sel = '0' else p2_HEX5;
68:     HEX6  <= p1_HEX6 when proj_sel = '0' else p2_HEX6;
69:     HEX7  <= p1_HEX7 when proj_sel = '0' else p2_HEX7;
70:     LEDR  <= p1_LEDR when proj_sel = '0' else p2_LEDR;
71:     LEDG  <= p1_LEDG when proj_sel = '0' else p2_LEDG;
72:     VGA_R <= p2_VGA_R when proj_sel = '1' else (others => '0');
73:     VGA_G <= p2_VGA_G when proj_sel = '1' else (others => '0');
74:     VGA_B <= p2_VGA_B when proj_sel = '1' else (others => '0');
75: 
76: end architecture structural;
```

- **Lines 40~46 (`U_PROJECT1`)**：从 `work` 库中直接实例化 `project1_top_countercalculator`（采用无需 `component` 声明的 VHDL-93 直接实例化语法）。`KEY` 连接至经过隔离的 `p1_KEY`，输出接入内部信号线 `p1_HEX0~7`、`p1_LEDR`、`p1_LEDG`。
- **Lines 49~59 (`U_PROJECT2`)**：实例化 `project2_top_mole_game`。`SW` 与 `KEY` 连接至隔离后的 `p2_SW`、`p2_KEY`，PS/2 鼠标和 VGA 同步信号直连外部引脚，而 `VGA_R/G/B` 先由 `p2_VGA_R/G/B` 接收，在 `SW(4)='0'` 时屏蔽为黑屏。
- **Lines 62~74（全局输出多路复用器）**：利用并行条件信号赋值语句 `when proj_sel = '0' else`，当 `SW(4)` 为 `'0'` 时输出 Project 1 的结果，为 `'1'` 时输出 Project 2 的结果至开发板 `HEX0~7`、`LEDR`、`LEDG` 引脚。（在硬件上各自综合为 2 选 1 多路复用器。）

#### [核心总结] `=>` 与 `<=` 符号的彻底区分

1. **`port map` 中的 `=>` 不表示“数据流动方向”，而是表示“连接（`=`）”！**
   - 它仅按 `子模块端口(左侧) => 当前文件信号线(右侧)` 的顺序进行配对绑定（作用类似于 Python 中的 `func(param=arg)`）。
   - **实际数据流向由子模块的 `in`/`out` 属性决定。**
     - `KEY => p1_KEY`（`KEY` 为 `in` 端口）：当前文件的 `p1_KEY` 值**传入**子模块 `KEY`（右 → 左）。
     - `HEX0 => p1_HEX0`（`HEX0` 为 `out` 端口）：子模块产生的 `HEX0` 结果**传出**到当前文件的 `p1_HEX0`（左 → 右）。
2. **`<=` 才是真正的“信号赋值（右 → 左）”！**
   - `HEX0 <= p1_HEX0 when proj_sel = '0' else p2_HEX0;`
   - 在 `p1_HEX0` 和 `p2_HEX0` 中二选一，输出到左侧 DE2 开发板的实际物理引脚 `HEX0`。
3. **示例（计算 `3 + 4 = 7` 时的信号流向）**：
   - ① 开发板 `SW` 值通过 `SW => SW` **进入** `U_PROJECT1` → ② `U_PROJECT1` 生成数字 `7` 的段码并通过 `HEX0 => p1_HEX0` **传出**至 `p1_HEX0` → ③ 通过 `HEX0 <= p1_HEX0 ...` **显示**在真正的开发板引脚 `HEX0` 上。

### 2.4 实际输入时跨文件信号传输路径追踪（按行追踪）

以下以两种典型场景为例，整理了在开发板上输入操作后，信号依次经过哪些文件的哪几行并最终输出到显示端（`HEX0`）的完整路径。

#### ① 计数器模式（`SW(4)='0'`, `SW(0)='0'`）下按下 `KEY(3)` 使数值 `0 → 1`
1. **[de2_unified_top.vhd](./de2_unified_top.vhd)（接收开发板输入）**：
   - `第 33 行`：因 `SW(4) = '0'`，`proj_sel` 变为 `'0'`。
   - `第 35 行`：因 `proj_sel = '0'`，`p1_KEY <= KEY`，按键值不被拦截，直接通过 `p1_KEY` 信号线。
   - `第 42 行`（`KEY => p1_KEY`）：`p1_KEY` 信号进入 `U_PROJECT1` 的 `KEY` 输入端口。
2. **[project1_top_countercalculator.vhd](./project1/project1_top_countercalculator.vhd)（传递至计数器）**：
   - `第 26 行`：因 `SW(0) = '0'`，`counter_enable <= '1'`。
   - `第 31 行`（`enable => counter_enable, KEY => KEY`）：`enable='1'` 与按键 `KEY` 进入子模块 `U_COUNTER`。
3. **[counter_unit.vhd](./project1/counter_unit.vhd)（数值递增 & 拆分数位）**：
   - `第 30~55 行`（`第 1 个 process`）：随 `CLOCK_50` 同步检测 `key_sync0`→`key_sync1` 的下降沿，`count_val` 从 `0` 变为 `1`。
   - `第 59~91 行`（`第 2 个 process`）：`count_val` 一旦变为 `1` 立即触发执行，在 `第 86 行` 调用 `seg7(1)`。
4. **[seg7_pkg.vhd](./project1/seg7_pkg.vhd)（转换为七段数码管段码）**：
   - `第 10~37 行`：调用 `seg7(1)` 后返回 `when 1 => return "1111001";`，该值从 `counter_unit.vhd` 的 `HEX0` 端口输出。
5. **返回 `project1_top_countercalculator.vhd`（子顶层 MUX）**：
   - `第 32 行`（`HEX0 => cnt_HEX0`）将 `"1111001"` 存入 `cnt_HEX0`，在 `第 48 行`（`SW(0) = '0'`）选中 `cnt_HEX0` 输出。
6. **返回 `de2_unified_top.vhd`（主顶层 MUX → 板载点亮）**：
   - `第 43 行`（`HEX0 => p1_HEX0`）接收该信号，在 `第 62 行`（`proj_sel = '0'`）选中 `p1_HEX0` 输出到 DE2 开发板的**物理 `HEX0` 引脚**，点亮显示 **`1`**。

#### ② 计算器模式（`SW(4)='0'`, `SW(0)='1'`）下计算 `3 + 4 = 7`
1. **`de2_unified_top.vhd`**：通过 `第 42 行`（`SW => SW`）将开关值送入 `U_PROJECT1`。
2. **`project1_top_countercalculator.vhd`**：在 `第 26 行` 将 `counter_enable <= '0'` 以暂停计数器，并在 `第 40~41 行` 将操作数和运算符开关传递给 `U_CALCULATOR`。
3. **[calculator_unit.vhd](./project1/calculator_unit.vhd)**：无需等待时钟，立即组合计算 `calc_result := 3 + 4 = 7`，随后调用 `seg7(7)`。
4. **`seg7_pkg.vhd`**：返回 `when 7 => return "1111000";`。
5. **返回 `project1_top_countercalculator.vhd`**：在 `第 42 行`（`HEX0 => calc_HEX0`）接收段码，在 `第 48 行`（`SW(0)='1'`）选中 `calc_HEX0` 输出。
6. **返回 `de2_unified_top.vhd`**：在 `第 43 行`（`HEX0 => p1_HEX0`）接收信号，在 `第 62 行`（`proj_sel='0'`）选中 `p1_HEX0` 输出，使 DE2 开发板的 **`HEX0` 显示 `7`**。

> **一句话总结**：信号总是按照 **主顶层（`de2_unified_top`）→ 子顶层（`project1_top`）→ 功能模块（`counter_unit` / `calculator_unit`）→ 解码器（`seg7_pkg`）** 的顺序向下传入，再带着转换后的结果**逐级返回（功能模块 → 子顶层 MUX → 主顶层 MUX → 板载引脚）** 输出到外设。

## 3. Project 1 详细说明（计数器 & 计算器）

### 3.1 `project1_top_countercalculator.vhd`（子顶层）
- 并行实例化 `U_COUNTER` 与 `U_CALCULATOR`，通过 **`SW(0)`** 切换功能与输出。
  - `counter_enable <= not SW(0);`（仅当 `SW(0) = '0'` 时计数器响应按键输入）
  - `HEX0~7`、`LEDR`、`LEDG` 通过 `when SW(0) = '0' else ...` 语句选择输出。

### 3.2 `counter_unit.vhd`（计数器模块）
- **同步按键下降沿检测**：采用 `key_sync0`、`key_sync1` 两级触发器消除亚稳态，仅在 `key_sync1 = '1' and key_sync0 = '0'`（按键按下瞬间）产生 1 个时钟周期的检测脉冲。
- **倍率选择 (`SW(1)`)**：`SW(1) = '0'` 时为 `×1` 倍率，`SW(1) = '1'` 时为 `×5` 倍率。
  - `KEY(3)`：`+1` / `+5`
  - `KEY(2)`：`+2` / `+10`
  - `KEY(1)`：`-1` / `-5`
  - `KEY(0)`：复位归 `0`
- **显示范围与彩蛋**：数值限幅在 `-999 ~ 9999`，`LEDR(13..0)` 以二进制显示绝对值（负数时 `LEDR(17)='1'`）；当数值达到 `777` 时，以 `blink_cnt(23)` 为周期令 `LEDR`/`LEDG` 全体闪烁，并在 `HEX7~4` 显示 `"JP77"`。

### 3.3 `calculator_unit.vhd`（一位数计算器模块）
- **纯组合逻辑电路**：将 `op_a_sw(SW(17..14))`、`op_b_sw(SW(13..10))` 限幅到 `0~9`，并分别显示在 `HEX6`、`HEX4` 上。
- **运算选择 (`SW(2..1)`)**：`"00"`(+)、`"01"`(-)、`"10"`(*)、`"11"`(/)。
- **进制与异常处理**：
  - `SW(3) = '0'` 时以十进制、`'1'` 时以十六进制在 `HEX2~HEX0` 上输出结果。
  - 除法中若 `num_b = 0`，则在 `HEX2~0` 显示 `"Err"` 并点亮全部 `LEDR`。
  - 正常除法时，`HEX2` 显示商，`HEX1..0` 显示 `"r" + 余数`（`LEDR(3..0)`=商，`LEDG(3..0)`=余数）。

## 4. Project 2 详细说明（打地鼠游戏）

### 4.1 `project2_top_mole_game.vhd`（子顶层）
充当连接 Project 2 内部 4 个硬件模块的信号布线枢纽。

```text
[CLOCK_50, KEY(3)] ──▶ U_VGA_CTRL ──(video_on, pixel_x/y, frame_tick)──┬──▶ U_VGA_RENDERER ──▶ VGA_R/G/B
                                                                        │
[PS2_CLK/DAT]      ──▶ U_PS2_MOUSE ──(cursor_x/y, mouse_lclick)─────────┼──▶ U_GAME_ENGINE  ──▶ (状态信号)
                                                                        │                          │
[SW(17..6), KEY(0)]─────────────────────────────────────────────────────┘                          ▼
                                                                                     [HEX7~0, LEDR, LEDG]
```

- **板载状态输出**：
  - `HEX7~5`：剩余金币（`050` ~ `000`）
  - `HEX4`：当前回合（`1` ~ `3`）
  - `HEX3~2`：剩余目标击杀数（`50 - kill_count`）
  - `HEX1~0`：当前回合剩余时间（`20` / `30` ~ `00`）
  - `LEDR(7..0)`：存活地鼠槽位指示 / `LEDR(15..8)`：正在偷挖金币的地鼠警告灯
  - `LEDG(3..0)`：锤击动画闪烁 / `LEDG(7..4)`：人类获胜（`game_state=1`）/ `LEDR(17..16)`：地鼠获胜（`game_state=2`）

### 4.2 `sprite_reward_pkg.vhd`（数据与字体包）
- `MAX_MOLES := 8`：同屏最大地鼠数量。
- `mole_rec_t` 记录与 `mole_array_t` 数组：打包管理单只地鼠的状态（`active`、`x`、`y`、`kind`[0=地鼠/1=龙头地鼠]、`hp`、`mining`、`mine_timer`）。
- **16×16 像素精灵 ROM**：人类（`SPRITE_HUMAN`）、地鼠（`SPRITE_DIGLETT`）、龙头地鼠（`SPRITE_EXCADRILL`）、金币堆（`SPRITE_COIN`）。
- **5×7 点阵字体 ROM (`get_font_pixel`)** 及弹窗文本表（`RULE_OVERLAY_TEXT` 10 秒规则说明，`REWARD_OVERLAY_TEXT` 50 MMC 奖励链接 `/r/1~5` 及领取码）。

### 4.3 `vga_controller.vhd`（VGA 时序发生器）
- 对 `CLOCK_50`（50MHz）进行 2 分频（`clk_25`），生成 **25MHz 像素时钟（`vga_clk`）**。
- 生成标准 **640×480 @ 60Hz** 时序：`H_TOTAL = 800`（有效 640 + 前肩 16 + 同步 96 + 后肩 48），`V_TOTAL = 525`（有效 480 + 前肩 10 + 同步 2 + 后肩 33）。
- 在每帧有效显示区结束时刻（`h_cnt = 0, v_cnt = 480`）输出 **1 个时钟周期宽度的 `frame_tick`（60Hz）** 脉冲，作为游戏物理引擎的时间基准。

### 4.4 `ps2_mouse_unit.vhd`（PS/2 鼠标控制器）
- 由 7 状态有限状态机组成（`INIT_WAIT` → `TX_PULL_CLK_LOW` → `TX_PULL_DAT_LOW` → `TX_SEND_BITS` → `TX_WAIT_ACK` → `RX_WAIT_ACK_BYTE` → `RX_STREAM_PACKETS`）。
- 上电或复位等待 40ms 后，以开漏方式向鼠标发送 **`0xF4`（Enable Data Reporting）** 命令；收到 `0xFA` ACK 响应后，连续接收 3 字节位移数据包（`Byte0` 按键/符号位，`Byte1` dX，`Byte2` dY）。
- 将接收到的位移量累加到左侧游戏地图范围（`0..479`）内的 `(cursor_x, cursor_y)` 坐标，并输出 `left_click`、`right_click`。

### 4.5 `game_engine_unit.vhd`（核心游戏引擎）
按 `frame_tick`（60Hz）节拍处理全部游戏规则。
- **开场 & 3 回合流程**：
  - 启动/复位（`KEY(3)=0`）时进入 `intro_sec = 10` 秒等待（7 秒规则说明 + 3 秒倒计时）。
  - 各回合限时：1R `20 秒`、2R `20 秒`、3R `30 秒`。金币（初始 `50` 枚）与连击数在回合间继承累计。
  - 金币归 `0` 时立即判定地鼠胜（`game_state = 2`）；撑过 3 回合或达成 50 击杀时判定人类胜（`game_state = 1`）。
- **Player 1（人类）**：
  - 朝向鼠标光标 `(cursor_x, cursor_y)` 进行 8 方向追踪移动（`2 px/f`，6 连击以上提速至 `3 px/f`）。
  - 鼠标左键点击或按下 `KEY(0)` 时，攻击半径 `R=48 px`（`ATTACK_RADIUS_SQ = 2304`）内**距离最近的 1 只地鼠**。
  - 连击奖励：3 连击（伤害 2）、6 连击（移速 3）、9 连击（4/8 概率暴击伤害 3）。空挥时硬直 `0.5 秒`（30 帧）且连击下降 1 级。
- **Player 2（地鼠召唤 — `SW(17..6)` 顺时针）**：
  - 每个 `60Hz` 帧扫描 `spawn_sw(11 downto 0)`（`SW(17..6)`）的**上升沿（`0 → 1`）**，自带天然防抖，并在空闲槽位（`active = '0'`）中召唤 1 只地鼠。
  - **顺时针 12 区域布局**：以 `SW(17)`=左上角 `(60, 50)` 为起点顺时针分布至 `SW(6)`=左侧偏上 `(50, 180)`。禁止在同一区域连续两次召唤。
  - 各回合龙头地鼠（2 倍血量、移速更快）出现概率：1R `1/8`、2R `2/8`、3R `4/8`。
- **地鼠 AI & 挖矿**：
  - 朝向中央金币堆 `(240, 240)` 进行 8 方向移动；进入 `MINE_DISTANCE(26 px)` 半径内后进入 `mining = '1'` 状态，每 60 帧（1 秒）扣除 1 枚金币。

### 4.6 `vga_renderer_unit.vhd`（实时 VGA 渲染器）
基于纯组合逻辑（以 `pixel_x, pixel_y` 为基准）实时决定每个像素的 10 位 RGB 颜色。
- **左侧 480×480 游戏地图 (`pixel_x < 480`)**：按层叠顺序绘制草地砖块背景、中央禁区虚线、半透明锤击范围圆（`R=48`）、金币堆、8 只地鼠（含血条）、玩家+铁锤、红色鼠标准星（`+`）。
- **右侧 160×480 状态栏 (`pixel_x >= 480`)**：渲染 `STAGE`、`COINS`、`TIME`、`COMBO LV`、`STATUS`、`KILLS` 进度条与数值。
- **中央弹窗**：游戏开始前（`intro_sec > 0`）在画面中央显示 `RULE_OVERLAY_TEXT` 与倒计时数字；游戏结束时（`game_state /= 0`）显示 `REWARD_OVERLAY_TEXT`（50 MMC 奖励链接与领取码）。
