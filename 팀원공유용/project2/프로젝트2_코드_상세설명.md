# 계층적 구조(Hierarchical Design) 기반 두더지 잡기 게임 (Crypto Miner Defense - 3 Rounds) VHDL 코드 & 문법 완벽 해설서

본 문서는 Altera/Intel **DE2 보드(Cyclone II `EP2C35F672C6`, 50MHz `CLOCK_50`)** 위에서 동작하는 **2인용 비대칭 PvP 크립토 디펜스 두더지 잡기 게임(Project 2)**의 모든 VHDL 소스코드에 대해 **발표(Source Code Presentation) 및 보고서 작성에 바로 활용할 수 있도록 줄 번호별로 뜯어본 상세 코드 해설서**입니다.

> [!NOTE]
> Project 2는 DE2 보드 푸시버튼 **`KEY(3..0)` 기반 망치 이동·공격**과 스위치 **`SW(17..6)` 시계방향 12구역 두더지 소환**을 사용하며, **총 3라운드(R1=10초, R2=10초, R3=15초), 누적 50코인, 10초 인트로(룰 안내 + 3초 카운트다운), 두더지 체력(HP) 및 콤보 진화 시스템, 50MHz 타이밍을 만족하는 9클럭 순차 타격 스캔 FSM**을 탑재하고 있습니다.

## 1. Project 2를 이해하기 위한 필수 VHDL 문법 6가지

1. **`record` (구조체)와 `array` 조합**: 두더지 1마리의 7가지 속성(`active`, `x`, `y`, `kind`, `hp`, `mining`, `mine_timer`)을 `mole_rec_t`로 묶고, `mole_array_t`로 8마리 슬롯(`0 to 7`)을 관리합니다.
2. **하드웨어 `for ... loop`와 `exit;`**: VHDL의 `for i in 0 to 7 loop`는 동일한 하드웨어 회로를 병렬 복사(Unrolling)합니다. 빈 슬롯 1개만 찾아 소환할 때는 반드시 `exit;`로 루프를 탈출해야 8마리가 동시에 소환되는 것을 막을 수 있습니다.
3. **파이프라인 순차 스캔 FSM (타이밍 최적화)**: 8마리의 거리 제곱(`dx^2 + dy^2`)을 1클럭에 모두 계산하면 조합 경로가 길어져 50MHz(20ns) 타이밍을 위반하므로, 클럭당 1마리씩 8클럭에 걸쳐 검사하고 9번째 클럭에 데미지를 적용하는 순차 FSM(`atk_scan_active`, `atk_scan_idx`)을 사용해 `Fmax > 72MHz`와 DSP 곱셈기 절약을 동시에 달성합니다.
4. **조합 `process` 로컬 변수 초기화 (Unsafe Latch 방지)**: 조합 논리 `process` 시작 직후 모든 `variable`(`hud_str := (others => ' ')` 등)을 기본값으로 초기화하여, 어떤 조건 분기에서도 의도치 않은 래치(Latch)가 생성되지 않도록 보장합니다.
5. **`procedure` (다중 출력 도우미)**: `function`은 값을 1개만 `return`하지만, `procedure set_rgb(...)`는 `r10`, `g10`, `b10` 3개 변수를 동시에 갱신합니다.
6. **문자열 인덱스 규칙 (`1 to N`)**: VHDL `string`은 인덱스가 `1`부터 시작하므로 `0..15` 좌표 변환 시 `(sprite_x + 1)`, `(char_col + 1)`처럼 `+1` 오프셋을 적용합니다.

## 3. 파일 1: [sprite_reward_pkg.vhd](./sprite_reward_pkg.vhd)

- **`MAX_MOLES := 8` 및 `mole_rec_t` (Lines 14~27)**:
  - `active`: `'1'`이면 생존, `'0'`이면 빈 슬롯.
  - `x, y`: 480×480 맵 내 좌표 (`0 to 511`).
  - `kind`: `'0'`은 일반 두더류(디그다, 초록 HP바), `'1'`은 특수 몰드류(엑스드릴, 빨간 HP바, 체력 2배·속도 빠름).
  - `hp`: 남은 체력(`0 to 7`). 라운드별로 두더류는 `1 / 2 / 3`, 몰드류는 `2 / 4 / 6`.
  - `mining`, `mine_timer`: 중앙 코인 더미 도달 여부와 1초(60프레임 `0..59`) 채굴 타이머.
- **스프라이트 ROM & 오버레이 텍스트 (Lines 37~221)**:
  - `SPRITE_DIGLETT`, `SPRITE_EXCADRILL`, 콤보 단계별 진화 망치 3종(`SPRITE_HAMMER_1/2/3`), 코인 더미(`SPRITE_COIN`).
  - `RULE_OVERLAY_TEXT`: 인트로 `10..4초` 구간에 표시되는 룰 설명(`R1/2:10s R3:15s | 50 COINS TOTAL`, `[P1 HUMAN] KEY3:UP KEY2/1:LR KEY0` 등).
  - `REWARD_OVERLAY_TEXT`: 게임 종료 시 표시되는 50 MMC 보상 링크(`/r/1~5`)와 16자리 1회용 수령 코드, 리셋 안내(`TOGGLE SW(4) OFF/ON TO RESET GAME`).

## 4. 파일 2: [vga_controller.vhd](./vga_controller.vhd)

- 50MHz `CLOCK_50`을 2분주하여 25MHz `vga_clk`를 생성하고, `H_TOTAL = 800`, `V_TOTAL = 525` 카운터로 640×480 @ 60Hz `hsync`, `vsync`, `video_on`, `pixel_x`, `pixel_y`를 출력합니다.
- 매 프레임의 표시 영역이 끝나는 `v_cnt = 480, h_cnt = 0`에서 1클럭 `frame_tick`(60Hz) 펄스를 발생시켜 게임 엔진의 물리/타이머 기준 클럭으로 공급합니다.

## 5. 파일 3: [game_engine_unit.vhd](./game_engine_unit.vhd)

### 5.1 상수, 좌표 LUT 및 상태 레지스터 (Lines 49~97)
- `CENTER_X/Y := 240`, `ATTACK_RADIUS_SQ := 48 * 48 = 2304`, `MINE_DISTANCE := 26`.
- `SPAWN_X_LUT`, `SPAWN_Y_LUT`: 중앙 금지구역(`140..340`) 바깥 외곽 12구역 시계방향 좌표.
- `sec_left := 10` (1R=`10초`, 2R=`10초`, 3R=`15초`), `coins := 50` (누적 50코인), `intro_sec := 10` (10초 인트로).
- `atk_scan_active`, `atk_scan_idx`, `atk_best_idx`, `atk_best_dist2`, `frame_pending`: 50MHz 타이밍 확보를 위한 9클럭 순차 타격 스캔 레지스터.

### 5.2 Player 1 망치 공격: 9클럭 순차 최단거리 스캔 FSM (Lines 174~254)
- `attack_req := not attack_key_n;` (`KEY(0)` 눌림 감지).
- 공격 시작 조건(`state = 0`, `intro_sec = 0`, `attack_req = '1' and atk_prev = '0'`, `atk_timer = 0`, `stun_timer = 0`) 만족 시 `atk_timer <= 12`(0.2초 애니메이션)와 함께 `atk_scan_active <= '1'`로 스캔을 시작합니다.
- `atk_scan_idx = 0..7` 동안 클럭당 두더지 1마리씩 `dist2 := dx*dx + dy*dy`를 계산해 사거리(`<= 2304`) 내 가장 가까운 두더지를 `atk_best_idx`에 갱신합니다.
- `atk_scan_idx = 8`에서:
  - 명중(`atk_best_idx /= -1`) 시 콤보 단계별 데미지(LV0=`1`, LV1/2=`2`, LV3=50% 확률 `3` / 50% `2`)를 입히고, 처치 시 `combo_cnt`를 `+1` 올립니다.
  - 헛스윙(`atk_best_idx = -1`) 시 `stun_timer <= 30`(0.5초 정지) 및 콤보 1단계 하락(`9+ → 6`, `6..8 → 3`, `0..5 → 0`)을 적용합니다.
- 스캔 도중 발생한 `frame_tick`은 `frame_pending <= '1'`로 보존하여 스캔 완료 직후 프레임 업데이트가 누락 없이 실행됩니다.

### 5.3 60Hz 프레임 업데이트: P1 `KEY(3..1)` 이동 · 라운드 전환 · 소환 · AI/채굴 (Lines 259~489)
- **Player 1 `KEY(3..1)` 이동 (Lines 271~312, 인트로 중에도 이동 가능)**:
  - **상하(`KEY(3)`)**: `move_up_n = '0'`(`KEY(3)` 누름)이면 위로(`py - player_spd`), 손을 떼면(`'1'`) 기본 방향인 아래로(`py + player_spd`) 일정하게 이동합니다.
  - **좌우(`KEY(2)`, `KEY(1)`)**: `KEY(2)`만 누르면 왼쪽(`px - player_spd`), `KEY(1)`만 누르면 오른쪽(`px + player_spd`), 둘 다 누르면 좌우 이동을 무시합니다.
  - 이동 속도는 기본 `2 px/f`(120 px/초), 6콤보 이상(LV2~3) 시 `3 px/f`(180 px/초)이며 맵 경계(`16..463`)로 클램핑됩니다.
- **승패 및 라운드 전환 (Lines 316~339)**:
  - `coins = 0`이면 즉시 두더지 승(`state <= 2`).
  - 남은 시간 `sec_left = 0`이 될 때까지 코인을 지키면 다음 라운드로 진행(2R=`10초`, 3R=`15초`, 코인·콤보 유지, 필드 두더지 초기화)하며, 3라운드 끝까지 버티면 인간 승(`state <= 1`).
- **Player 2 `SW(17..6)` 소환 및 두더지 AI/채굴 (Lines 354~484)**:
  - `SW(17..6)` 상승 에지로 외곽 12구역에 최대 8마리 소환(동일 구역 연속 소환 금지).
  - 라운드별 스펙:
    - 1라운드(10초): 일반 HP `1`(0.5 px/f), 몰드류 HP `2`(1.0 px/f, 확률 `1/8`)
    - 2라운드(10초): 일반 HP `2`(1.0 px/f), 몰드류 HP `4`(1.5 px/f, 확률 `2/8`)
    - 3라운드(15초): 일반 HP `3`(1.5 px/f), 몰드류 HP `6`(2.0 px/f, 확률 `4/8`)
  - 중앙 `(240, 240)` 기준 `26 px` 이내 도착 시 `mining <= '1'`이 되어 1.0초(60프레임)마다 코인을 1개씩 차감합니다.

## 6. 파일 4: [vga_renderer_unit.vhd](./vga_renderer_unit.vhd)

- **래치 방지 초기화 (Lines 123~141)**: 조합 `process` 시작 시 모든 로컬 변수(`r`, `g`, `b`, `hud_str := (others => ' ')` 등)를 기본값으로 초기화하여 Quartus 합성 시 Unsafe Latch가 전혀 생기지 않습니다.
- **좌측 480×480 게임 맵**: 잔디 타일(Layer A), 소환 금지구역 점선(Layer B), 반투명 망치 공격 범위 원 `R=48`(Layer C), 중앙 코인 더미(Layer D), 두더지 8마리 및 3px 체력바(Layer E), 진화하는 망치 스프라이트(Layer F), 망치 중심 조준점 `+`(Layer G).
- **우측 160×480 상태창**: `STAGE 1/3..3/3`, `COINS: XX` 및 코인 바, `TIME: XXs` 및 타이머 바(1·2R: `time_left_sec * 10`, 3R: `time_left_sec * 20 / 3`), `COMBO: XX` 및 단계(`LV0 NORMAL` ~ `LV3 CRIT3!`), `PLAYING / P1 WIN! / P2 WIN!` 상태 박스.
