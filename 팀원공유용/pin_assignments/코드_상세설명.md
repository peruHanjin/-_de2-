# DE2 보드 핀 할당(Pin Assignments) 안내서

본 폴더(`pin_assignments`)는 Altera/Intel **DE2 보드 (Cyclone II `EP2C35F672C6`)**에서 통합 최상위 모듈(`de2_unified_top`) 및 Project 2를 합성할 때 Quartus에 한 번에 불러올 수 있는 핀 매핑 파일들을 포함하고 있습니다.

---

## 1. 파일 목록 및 용도

| 파일명 | 대상 프로젝트 | 포함 핀 구성 | 사용 방법 |
| :--- | :--- | :--- | :--- |
| **[project2_pin_assignments.csv](./project2_pin_assignments.csv)** | **통합 최상위(`de2_unified_top`) & Project 1·2 전체** | `CLOCK_50`, `SW[17:0]`, `KEY[3:0]`, `HEX0~HEX7`, `LEDR[17:0]`, `LEDG[7:0]` + **`VGA` 출력 핀(35개)** + **`PS/2` 핀(2개, Quartus 142핀 순서 호환)** (총 142핀) | Quartus 메뉴 `Assignments -> Import Assignments...`에서 선택 |
| **[project2_pin_locations_only.txt](./project2_pin_locations_only.txt)** | **통합 최상위(`de2_unified_top`)** | 142핀 위치 번호 요약본 (Quartus Pin Planner 정렬 순서 일치) | 핀 번호 빠른 대조 및 일괄 붙여넣기용 |

## 2. Project 2 추가 외부 모듈 핀 매핑 요약 (`project2_pin_assignments.csv`)

### 2.1 VGA 모니터/TV 출력 (ADV7123 10-bit DAC ➔ VGA / VGA-to-HDMI 컨버터)
| VHDL 포트명 | DE2 핀 번호 | 설명 |
| :--- | :--- | :--- |
| **`VGA_CLK`** | `PIN_B8` | 25MHz VGA 픽셀 클럭 |
| **`VGA_HS`, `VGA_VS`** | `PIN_A7`, `PIN_D8` | 수평 동기(H-Sync) 및 수직 동기(V-Sync) |
| **`VGA_BLANK`, `VGA_SYNC`** | `PIN_D6`, `PIN_B7` | DAC 블랭킹 및 동기 제어 신호 |
| **`VGA_R[9:0]`** | `PIN_C8`, `F10`, `G10`, `D9`, `C9`, `A8`, `H11`, `H12`, `F11`, `E10` | Red 채널 10비트 |
| **`VGA_G[9:0]`** | `PIN_B9`, `A9`, `C10`, `D10`, `B10`, `A10`, `G11`, `D11`, `E12`, `D12` | Green 채널 10비트 |
| **`VGA_B[9:0]`** | `PIN_J13`, `J14`, `F12`, `G12`, `J10`, `J11`, `C11`, `B11`, `C12`, `B12` | Blue 채널 10비트 |
