# DE2 통합 프로젝트 (Project 1 + Project 2) 전체 구조 및 코드 해설서

본 문서는 Altera/Intel **DE2 보드 (Cyclone II `EP2C35F672C6`, 50MHz `CLOCK_50`)** 위에서 동작하는 **Project 1(카운터 & 한 자리 계산기)**과 **Project 2(크립토 마이너 디펜스 두더지 잡기 게임)**의 **전체 VHDL 소스코드 역할, 계층 구조, 모듈 간 신호 연결**을 정리한 기술 문서입니다.

---

## 1. 전체 계층 구조 (System Hierarchy)

하나의 Quartus 프로젝트(`de2_unified_top`) 안에 총 **8개의 VHDL 파일**이 계층적으로 연결되어 있으며, **`SW(4)`** 스위치 하나로 Project 1과 Project 2를 실시간 전환(및 Project 2 리셋)합니다.

```text
de2_unified_top.vhd  (마스터 최상위 엔티티, SW(4) 모드 전환)
│
├── [SW(4) = '0'] ──▶ project1_top_countercalculator.vhd  (Project 1 단일 파일 통합본)
│                     ├── [SW(0) = '0'] : 업/다운 카운터 (-999~9999) + 777 잭팟
│                     └── [SW(0) = '1'] : 한 자리 사칙연산 계산기 (+,-,*,/, Dec/Hex, 0 나눗셈 예외처리)
│
└── [SW(4) = '1'] ──▶ project2_top_mole_game.vhd          (Project 2 서브 탑)
                      ├── vga_controller.vhd     (640x480 @ 60Hz 타이밍, frame_tick)
                      ├── game_engine_unit.vhd   (3라운드 R1/2=10s·R3=15s, KEY(3..0) 조작, SW(17..6) 소환, 9클럭 순차 타격 스캔)
                      └── vga_renderer_unit.vhd  (실시간 도트 그래픽 & 인트로/보상 오버레이)

[공용 패키지 참조 (use work.*)]
├── seg7_pkg.vhd           ──▶ project2_top_mole_game (7-Segment 디코더)
└── sprite_reward_pkg.vhd  ──▶ game_engine_unit, vga_renderer_unit, project2_top_mole_game
```

## 2. 마스터 최상위 모듈: `de2_unified_top.vhd` (줄별 상세 해설)

[de2_unified_top.vhd](./de2_unified_top.vhd)는 DE2 보드의 물리 핀(`CLOCK_50`, `SW`, `KEY`, `HEX0~7`, `LEDR`, `LEDG`, `VGA_*`)을 직접 받아 내부의 `U_PROJECT1`과 `U_PROJECT2`로 분배하고, 비활성 프로젝트의 상태를 안전하게 격리하는 **마스터 최상위(Top-Level) 엔티티**입니다.

### 2.1 라이브러리 및 엔티티(Entity) 선언부 (Lines 1~16)

```vhdl
 1: library ieee;
 2: use ieee.std_logic_1164.all;
 3: 
 4: -- Master Top-Level Entity: de2_unified_top (SW(4)='0' -> Project 1, SW(4)='1' -> Project 2)
 5: entity de2_unified_top is
 6:     port (
 7:         CLOCK_50                                        : in    std_logic;
 8:         SW                                              : in    std_logic_vector(17 downto 0);
 9:         KEY                                             : in    std_logic_vector(3 downto 0);
10:         HEX0, HEX1, HEX2, HEX3, HEX4, HEX5, HEX6, HEX7  : out   std_logic_vector(6 downto 0);
11:         LEDR                                            : out   std_logic_vector(17 downto 0);
12:         LEDG                                            : out   std_logic_vector(7 downto 0);
13:         VGA_CLK, VGA_HS, VGA_VS, VGA_BLANK, VGA_SYNC    : out   std_logic;
14:         VGA_R, VGA_G, VGA_B                             : out   std_logic_vector(9 downto 0)
15:     );
16: end entity de2_unified_top;
```

- **Lines 1~2**: 표준 디지털 신호(`std_logic`, `std_logic_vector`)를 사용하기 위해 `ieee.std_logic_1164`를 불러옵니다.
- **Line 7 (`CLOCK_50 : in std_logic;`)**: DE2 보드 내장 50MHz 클럭을 받아 Project 1과 Project 2 양쪽에 동시에 공급합니다.
- **Lines 8~9 (`SW`, `KEY`)**: DE2 보드의 18개 토글 스위치(`SW(17..0)`)와 4개 Active-Low 푸시버튼(`KEY(3..0)`) 입력입니다.
- **Lines 10~12 (`HEX0~7`, `LEDR`, `LEDG`)**: 두 프로젝트가 보드의 7-Segment 8자리, 적색 LED 18개, 녹색 LED 8개를 공유하므로 `SW(4)` 상태에 따라 어느 프로젝트의 출력을 내보낼지 선택합니다.
- **Lines 13~14 (`VGA_*`)**: DE2 보드의 ADV7123 VGA DAC 칩으로 나가는 25MHz 클럭(`VGA_CLK`), 수평/수직 동기(`VGA_HS`, `VGA_VS`), 블랭킹/싱크(`VGA_BLANK`, `VGA_SYNC`), 10비트 RGB 색상(`VGA_R`, `VGA_G`, `VGA_B`) 출력입니다.

### 2.2 내부 신호 선언 및 입력 격리(Isolation) 로직 (Lines 18~36)

```vhdl
33:     proj_sel <= SW(4);
34:     p1_KEY   <= KEY when proj_sel = '0' else "1111";
35:     p2_KEY   <= KEY when proj_sel = '1' else "1111";
36:     p2_SW    <= SW  when proj_sel = '1' else (others => '0');
```

- **Line 33 (`proj_sel <= SW(4);`)**:
  - Project 1은 `SW(3..0)`(모드/연산/진법)과 `SW(17..10)`(피연산자 A, B)을 사용하고, Project 2는 `SW(17..6)`(두더지 12구역 소환)을 사용합니다.
  - 따라서 양쪽 모두 사용하지 않는 **`SW(4)`**를 마스터 프로젝트 전환 스위치로 지정했으며, `SW(5)`는 두더지 소환 스위치(`SW(6)`) 바로 옆에서 실수로 `SW(4)`를 건드리지 않도록 두는 **물리적 완충 간격(Buffer Gap)**입니다.
- **Line 34 (`p1_KEY <= KEY when proj_sel = '0' else "1111";`)**:
  - Project 2를 플레이하는 동안(`proj_sel = '1'`) 사용자가 `KEY(3..0)`(망치 이동/공격)을 눌러도 Project 1의 카운터 값이 변하지 않도록, 비활성 시 Project 1에는 `"1111"`(모든 버튼 해제 상태)을 넣어 격리합니다.
- **Lines 35~36 (`p2_KEY`, `p2_SW`)**:
  - Project 1을 쓰는 동안(`proj_sel = '0'`)에는 `p2_SW`가 모두 `'0'`이 되어 `project2_top_mole_game` 내부의 `reset_n <= SW(4)`가 `'0'`(리셋 상태)으로 유지됩니다.
  - `SW(4)`를 `'1'`로 올리는 순간 리셋이 풀려 Project 2 인트로(10초 룰 안내 + 카운트다운)가 처음부터 시작되며, `SW(4)`를 껐다 켜면 언제든 Project 2가 리셋됩니다.

### 2.3 하위 프로젝트 인스턴스화 및 글로벌 출력 멀티플렉서 (Lines 38~74)

```vhdl
60:     -- 3. Global Output Multiplexer (SW(4) = '0' -> Project 1, SW(4) = '1' -> Project 2)
61:     HEX0  <= p1_HEX0 when proj_sel = '0' else p2_HEX0;
...
71:     VGA_R <= p2_VGA_R when proj_sel = '1' else (others => '0');
72:     VGA_G <= p2_VGA_G when proj_sel = '1' else (others => '0');
73:     VGA_B <= p2_VGA_B when proj_sel = '1' else (others => '0');
```

- `SW(4) = '0'`일 때는 Project 1의 `HEX0~7`, `LEDR`, `LEDG`를 출력하고 VGA 화면은 검은색(`0`)으로 가리면서 모니터 동기 신호(`VGA_HS`, `VGA_VS`)는 유지합니다.
- `SW(4) = '1'`일 때는 Project 2의 `HEX0~7`, `LEDR`, `LEDG`, `VGA_R/G/B`를 출력합니다.

## 3. Project 1 상세 설명 (카운터 & 계산기 — 단일 파일 통합본)

[project1_top_countercalculator.vhd](./project1/project1_top_countercalculator.vhd)는 카운터, 한 자리 계산기, 7-Segment 디코더 함수 `seg7()`을 하나의 파일(214줄)에 통합한 모듈입니다. (줄 단위 상세 해설은 [프로젝트1_코드_상세설명.md](./project1/프로젝트1_코드_상세설명.md) 참조)

- **`SW(0) = '0'` (카운터 모드)**:
  - `key_sync0`, `key_sync1` 2단 동기화 플립플롭으로 버튼 하강 에지(`'1' → '0'`)를 검출합니다.
  - `SW(1) = '0'`이면 `×1`, `SW(1) = '1'`이면 `×5` 배율 적용 (`KEY(3)`: `+1/+5`, `KEY(2)`: `+2/+10`, `KEY(1)`: `-1/-5`, `KEY(0)`: `0` 리셋).
  - 범위 `-999 ~ 9999`, `LEDR(13..0)` 절댓값 이진수 표시(음수 시 `LEDR(17)='1'`), `777` 도달 시 `"JP77"` 잭팟 점멸.
- **`SW(0) = '1'` (한 자리 계산기 모드)**:
  - `SW(17..14)`(피연산자 A, `0~9` 클램핑 → `HEX6`), `SW(13..10)`(피연산자 B, `0~9` 클램핑 → `HEX4`).
  - `SW(2..1)`: `"00"`(+), `"01"`(-), `"10"`(*), `"11"`(/). `SW(3)`: `'0'`=10진수, `'1'`=16진수.
  - `0`으로 나눌 때 `"Err"` 및 `LEDR` 전체 점등, 정상 나눗셈 시 `HEX2`=몫, `HEX1..0`=`"r" + 나머지`.

## 4. Project 2 상세 설명 (두더지 잡기 게임)

### 4.1 `project2_top_mole_game.vhd` (서브 탑)
Project 2 내부의 3개 하드웨어 모듈(`U_VGA_CTRL`, `U_GAME_ENGINE`, `U_VGA_RENDERER`)을 신호선으로 연결하고 보드 표시 장치를 구동합니다.

```text
[CLOCK_50]         ──▶ U_VGA_CTRL ──(video_on, pixel_x/y, frame_tick)──┬──▶ U_VGA_RENDERER ──▶ VGA_R/G/B
                                                                        │
[SW(4), KEY(3..0)] ────────────────────────────────────────────────────┼──▶ U_GAME_ENGINE  ──▶ (상태 신호들)
[SW(17..6)]        ────────────────────────────────────────────────────┘                          │
                                                                                                  ▼
                                                                                    [HEX7~0, LEDR, LEDG]
```

- **리셋 (`reset_n <= SW(4);`)**: `SW(4)`가 `'0'`이면 리셋 대기, `'1'`이면 게임 실행.
- **온보드 7-Segment (`HEX7~0`) 출력**:
  - `HEX7, HEX6`: 남은 코인 (`50` ~ `00`)
  - `HEX5`: 꺼짐 (`seg7(16)`)
  - `HEX4`: 현재 라운드 (`1` ~ `3`)
  - `HEX3, HEX2`: 꺼짐 (`seg7(16)`)
  - `HEX1, HEX0`: 현재 라운드 남은 시간 (1·2R `10`~`00`, 3R `15`~`00`)
- **온보드 LED (`LEDR`, `LEDG`) 출력**:
  - `LEDR(15..8)`: 코인 채굴 중인 두더지 경고등 (슬롯 `0~7`의 `moles(i).mining`) — 나머지 `LEDR`은 항상 꺼짐
  - `LEDG(3..0)`: 망치 공격 애니메이션 표시 (`attack_anim > 0`일 때 점등) — 나머지 `LEDG`는 항상 꺼짐

### 4.2 `sprite_reward_pkg.vhd` (데이터 & 폰트 패키지)
- `MAX_MOLES := 8`: 동시 등장 최대 두더지 수.
- `mole_rec_t` 레코드 및 `mole_array_t` 배열: 두더지 1마리의 상태(`active`, `x`, `y`, `kind`[0=두더류/1=몰드류], `hp`, `mining`, `mine_timer`)를 관리.
- **16×16 도트 스프라이트 ROM**: 두더류(`SPRITE_DIGLETT`), 몰드류(`SPRITE_EXCADRILL`), 3단계 진화 망치(`SPRITE_HAMMER_1/2/3`), 코인 더미(`SPRITE_COIN`).
- **5×7 비트맵 폰트 ROM (`get_font_pixel`)** 및 오버레이 텍스트 테이블(`RULE_OVERLAY_TEXT` 10초 룰 안내, `REWARD_OVERLAY_TEXT` 50 MMC 보상 링크 `/r/1~5` 및 수령 코드).

### 4.3 `vga_controller.vhd` (VGA 타이밍 생성기)
- `CLOCK_50`(50MHz)을 2분주(`clk_25`)해 **25MHz 픽셀 클럭(`vga_clk`)** 생성.
- 표준 **640×480 @ 60Hz** 타이밍 생성 및 매 프레임 종료 시점(`h_cnt = 0, v_cnt = 480`)에 **1클럭 `frame_tick`(60Hz)** 펄스 출력.

### 4.4 `game_engine_unit.vhd` (핵심 게임 엔진)
- **인트로 & 3라운드 시간 생존 규칙**:
  - 시작/리셋(`SW(4) = '0' → '1'`) 시 `intro_sec = 10`초 대기(7초 룰 설명 + 3초 카운트다운). 인트로 중에도 망치 이동 가능.
  - 라운드별 제한시간: **1R `10초`, 2R `10초`, 3R `15초`**. 코인(초기 `50`개)과 콤보는 라운드 간 누적.
  - 코인이 `0`이 되면 즉시 두더지 승(`game_state = 2`), 각 라운드 제한 시간(`sec_left = 0`)까지 버티면 다음 라운드로 넘어가며 3라운드 끝까지 코인을 1개 이상 지키면 인간 승(`game_state = 1`).
- **Player 1 (인간 — `KEY(3..0)` 조작)**:
  - **상하 이동 (`KEY(3)`)**: 기본 상태(`KEY(3)` 안 누름)에서는 일정한 속도로 **아래(`+Y`)**로 내려가며, **`KEY(3)`을 누르고 있는 동안 위(`-Y`)**로 올라갑니다. 손을 떼면 다시 아래로 내려갑니다.
  - **좌우 이동 (`KEY(2)`, `KEY(1)`)**: `KEY(2)`를 누르면 왼쪽(`-X`), `KEY(1)`을 누르면 오른쪽(`+X`)으로 이동하여 상하 이동과 함께 대각선 및 벽면 수평 이동을 구현합니다. **`KEY(2)`와 `KEY(1)`이 동시에 눌리면 좌우 입력을 무시**합니다.
  - **망치 공격 (`KEY(0)`) & 9클럭 순차 최단거리 스캔 FSM**:
    - `KEY(0)`을 누르면 50MHz 클럭당 두더지 1마리씩 총 9클럭(`180 ns`) 동안 반경 `R=48 px`(`ATTACK_RADIUS_SQ = 2304`) 이내 가장 가까운 두더지(`atk_best_idx`)를 순차 탐색해 타격합니다. (스캔 중 도착한 `frame_tick`은 `frame_pending`으로 보존해 50MHz 타이밍 여유 `Fmax > 72MHz` 확보)
    - 콤보 보너스: `0~2`콤보(LV0, 데미지 `1`, 속도 `2 px/f`), `3~5`콤보(LV1, 데미지 `2`), `6~8`콤보(LV2, 데미지 `2`, 속도 `3 px/f`), `9+`콤보(LV3, 50% 확률 크리티컬 데미지 `3` / 50% 데미지 `2`, 속도 `3 px/f`).
    - 헛스윙 시 `0.5초`(30프레임) 이동·공격 경직(`stun_timer <= 30`) 및 콤보 1단계 하락.
- **Player 2 (두더지 소환 — `SW(17..6)` 시계방향) & AI/채굴**:
  - `SW(17)`(Zone 0 좌상단) ~ `SW(6)`(Zone 11) 상승 에지(`0 → 1`) 감지 시 최대 8마리까지 소환 (동일 구역 연속 소환 차단).
  - 라운드별 체력 및 몰드류 확률: 1R(일반 HP `1` / 몰드류 HP `2`, 확률 `1/8`), 2R(일반 HP `2` / 몰드류 HP `4`, 확률 `2/8`), 3R(일반 HP `3` / 몰드류 HP `6`, 확률 `4/8`).
  - 중앙 `(240, 240)` 반경 `26 px` 이내 도달 시 1.0초(60프레임)마다 코인 1개씩 차감.

### 4.5 `vga_renderer_unit.vhd` (실시간 VGA 렌더러)
- 조합 `process` 시작 시 모든 로컬 변수(`hud_str` 포함)를 초기화하여 래치(Unsafe Latch) 추론을 원천 차단합니다.
- **좌측 480×480 게임 맵**: 잔디 타일 배경, 중앙 금지구역 점선, 반투명 망치 사거리 원(`R=48`), 코인 더미, 8마리 두더지(체력바 포함), 진화하는 망치 스프라이트, 망치 중심 조준점(`+`) 렌더링.
- **우측 160×480 상태창**: `STAGE`, `COINS`, `TIME`(1·2R 10초, 3R 15초 비례 게이지), `COMBO LV`, `STATUS`(`PLAYING` / `P1 WIN!` / `P2 WIN!`) 렌더링.
- **중앙 오버레이 창**: 인트로(`intro_sec > 0`) 룰 안내/카운트다운 및 게임 종료(`game_state /= 0`) 50 MMC 보상 링크/코드 출력.
